# PlacementIQ
PlacementIQ is an AI-powered placement readiness platform using Supervised Machine Learning and Random Forest Classification to predict student readiness. It offers student management, skill gap analysis, job matching, resume building, interview preparation, and placement analytics.

**PlacementIQ – AI-Powered Placement Intelligence & Student Readiness Prediction Platform**

PlacementIQ is an intelligent, machine-learning-based platform designed to evaluate students' placement readiness and help them prepare for career opportunities. It uses **Supervised Machine Learning** with a Random Forest Classification model to predict a student's readiness level based on academic performance, coding skills, aptitude, communication skills, projects, internships, certifications, and attendance.

The platform provides student management, AI-based readiness prediction, skill gap analysis, job matching, resume building, interview preparation, application tracking, and ML analytics through an interactive dashboard.

**Tech Stack:** Python, FastAPI, Scikit-learn, Pandas, React.js, TypeScript, Vite, and Machine Learning.

**Goal:** To help students understand their strengths, identify areas for improvement, and make more informed decisions about their placement preparation.
